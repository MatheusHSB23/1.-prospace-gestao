# Atualização de responsividade — ProSpace Health Gestão

Esta atualização modifica somente a interface do painel:

- A barra de rolagem da navegação lateral fica oculta visualmente, mas a rolagem continua funcionando com mouse, roda, trackpad e toque.
- Em celulares, o menu lateral abre como uma gaveta com fundo escurecido.
- O menu pode ser fechado pelo botão de menu, ao tocar fora, ao selecionar uma página ou pressionar Esc.
- Cabeçalho, cartões, formulários, tabelas, relatórios, modais e avisos foram ajustados para telas estreitas.
- Foram preservados a logo, os ícones brancos, as configurações do Supabase e os arquivos de dados demonstrativos já incluídos no pacote.

## Instalação

1. Faça uma cópia de segurança da pasta atual `ProSpace_Health_Gestao`.
2. Extraia o pacote completo atualizado e utilize a pasta `ProSpace_Health_Gestao` extraída.
   - Ou, se preferir aplicar somente a atualização, substitua `index.html`, `styles.css` e `app.js` na pasta já instalada pelos arquivos do pacote de patch.
3. Não é necessário executar SQL nem alterar o Supabase.
4. Reinicie `INICIAR_GESTAO.bat` e atualize o navegador com `Ctrl + F5`.
